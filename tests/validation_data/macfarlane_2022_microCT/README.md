# Macfarlane et al. 2022 — MOSAiC microCT snow profiles (staged for forward-closure validation)

**DOI:** [10.1594/PANGAEA.952794](https://doi.org/10.1594/PANGAEA.952794) ·
part of the MOSAiC snowpit bundle
[935934](https://doi.org/10.1594/PANGAEA.935934).
Macfarlane, Schneebeli, Wagner, Dadic, Jaggi, Hämmerle (2022): *MicroCT density
and specific surface area snowpit profiles during the MOSAiC expedition.*

## Why this is here

Our existing sea-ice validation (`docs/sea_ice_validation.md`) uses the
**Smith/Light/Perovich MOSAiC spectral albedo** dataset (`../smith_2021/`,
`doi:10.18739/A2FT8DK8Z`) as an independent hold-out — but its surface labels
are *classified*, not measured; only Morassutti pond depths are true ground
truth. This dataset supplies the **measured snow drivers** BioSNICAR needs —
**density and specific surface area (SSA) vs depth** — from microCT scans of
snow cores, sampled on the **same floe, same days** as the Smith spectra.

That turns the Smith spectra from a classification hold-out into a **forward
closure test**: configure BioSNICAR from measured SSA/density (no free
parameters), run it forward, and compare the modelled spectrum to the observed
albedo line. This is the strongest validation claim available to us —
measured-in → predicted-out, no tuning against the target.

## What was staged (melt season only)

- `index_summer2020.csv` — the dataset's master index, filtered to
  **June–September 2020** (117 pits): event, date, lat/lon, xlsx filename,
  site/location label, sample top/bottom relative height, comment.
- `profiles/*.xlsx` — 116 microCT profiles (one per pit). Each holds a
  numeric depth profile: **density (kg/m³), SSA (m²/kg), anisotropy**, plus
  `y position in sample`, `y position in snowpit` (0 mm = sea-ice surface),
  and `relative_depth` (1 = snow top, 0 = ice interface). ~89 rows/pit.
- Winter pits (Nov 2019–May 2020) were **deliberately excluded** — no sunlight,
  so no coincident spectral albedo to close against.

Downloaded from the open per-file endpoint
`https://download.pangaea.de/dataset/952794/files/<name>.xlsx` (no auth).
Re-fetch: `_xlsx_list.txt` holds the filenames.

## Data reality (RESOLVE BEFORE RUNNING CLOSURE)

Verified by inspecting the actual profiles — three gotchas:

1. **Variant selection.** Each pit ships as `Cxxxxxxx_1.xlsx` and
   `_2.xlsx`. The `_1` is geometry-only (`density`=0, `ssa`=NaN); the **`_2`
   variant carries the physical profile**. 108 of 116 staged files have real
   data. The loader must pick the populated variant, not the first alphabetically.

2. **Column alignment.** openpyxl/pandas mis-associate the header row with the
   data columns — read with `header=None` and anchor the profile columns from
   the **right edge**: last 8 columns are
   `density, ssa, y, Anisotropy, EventDate, position_in_sample_mm,
   position_in_snowpit_mm, relative_depth(%)`. Requires `openpyxl` (added to the
   venv; add to project deps if this becomes a committed test).

3. **SSA units are ambiguous and matter ~900×.** Observed `density` is
   physical (kg/m³, 5–95th pct ≈ 150–870; the high end is dense refrozen /
   surface-scattering-layer, the low end is snow). Observed `ssa` ≈ 0.2–9
   (median ~1.9) in *unstated* units. Grain radius is
   `r_eff = 3 / (ρ_ice · SSA_mass)` with `ρ_ice = 917 kg/m³` **only if SSA is
   mass-specific (m²/kg)** — giving r_eff ≈ 350 µm–1.7 mm (coarse, plausible for
   melt-metamorphosed summer snow/SSL). If instead the column is *volume*-
   specific (mm⁻¹), the conversion drops the ρ_ice factor and r_eff changes by
   ~900×. **Confirm against the Macfarlane 2023 Scientific Data methods
   (`doi:10.1038/s41597-023-02273-1`) before trusting any retrieval.** The
   closure script guards this with a runtime plausibility assertion on r_eff.

> **Depth registration.** Use `relative_depth(%)` (1 = snow top, 0 = sea-ice
> interface) to compose layers, not raw mm — pits have different total depths.
> `position_in_snowpit_mm` is measured up from the sea-ice surface.

## Suggested next step (Tier-1 forward closure)

1. For each of the 35 shared days, pick the microCT pit and the albedo-line
   spectrum at the matching site.
2. Bin the microCT SSA/density into BioSNICAR snow layers via `relative_depth`;
   convert SSA → effective grain radius (r_eff = 3/(ρ_ice·SSA)).
3. Run BioSNICAR forward with the recorded MOSAiC solar geometry (high SZA,
   60–85° — do **not** use a default zenith) and diffuse fraction.
4. Compare modelled vs observed albedo across 350–2500 nm; report residuals
   stratified by surface state (dry/melting snow). No parameters fitted.

Implemented in `macfarlane_forward_closure.py` (reuses the audited Smith
parser). Reproduce:

```
python macfarlane_forward_closure.py --json closure_results.json --plot figures/
```

## First-look result (SSA assumed m²/kg, 2026-07-18)

6 usable snow pairs (the other 20 verified pairs are bare-ice STERN sites with
no snow positions in the albedo data — correctly skipped). No parameters fitted.

| metric | median RMSE |
|---|---|
| all (350–2000 nm) | **0.120** |
| visible (≤750 nm) | 0.193 |
| NIR (>750 nm) | 0.082 |

Bias is **positive everywhere** (+0.02 to +0.12): the model runs brighter than
observed. See `figures/forward_closure_spectra.png` and `closure_results.json`.

**Interpretation — and why this validates the m²/kg assumption.** The spectral
*shape* tells the story the aggregate RMSE hides:

- **NIR (>1000 nm) matches well** in both level and the ice-absorption features
  (~1030, 1250 nm dips align; both →0 past 1500 nm). NIR albedo is
  *grain-size-controlled*, so a correct NIR is direct evidence the microCT
  grain radii — hence the **SSA=m²/kg conversion** — are approximately right.
  A wrong-by-ρ_ice (~900×) unit error would blow the NIR up; it doesn't.
- **The error is a VIS positive offset** (~0.1–0.25), largest at the melting
  low-albedo ROV sites. A vertical visible offset with intact NIR shape is the
  classic signature of **unmodelled light-absorbing impurities** (MOSAiC summer
  snow carried sediment/algae) **and substrate darkening** (melting ice below
  is darker than our clean nominal FYI) — *not* a snow-driver error. We ran with
  zero impurities and a fixed substrate, so this offset is expected.

So the first closure is a genuinely encouraging outcome: the measured snow
microphysics predict the grain-size-sensitive NIR correctly, and the residual
localises cleanly to two known missing ingredients. Caveats stand: n=6, Leg 4
only; 2–4 of 5 layers were clamped to the 1500 µm snow-LUT ceiling on some pits
(coarse melt grains); the m²/kg unit is now *supported* but still merits the
documentation cross-check in §Data reality.

## Second run — measured snow thickness + melting-ice substrate (2026-07-20)

Tightened the closure toward "measured-in" with two changes, both from observed
data (no fitting): snow **total depth set to the Smith albedo line's measured
per-position snow thickness** (2.6–10.6 cm at these pairs), and the substrate
swapped from a single clean FYI layer to the SHEBA-calibrated
**`FYI_SUMMER_BARE`** preset (SSL + drained + interior melting ice). microCT
still supplies the snow density/SSA/grain structure. Figures:
`figures/closure_before_after_spectra.png`, `figures/closure_rmse_before_after.png`.

| metric | prior | measured+summer-bare |
|---|---|---|
| median RMSE all | 0.120 | 0.116 |
| median RMSE visible | 0.193 | **0.175** |

**The change barely moved the fit — and that is the scientific result.** The
substrate helps *only* where snow is thin enough to see through it: the 2.6 cm
case (2020-07-04 ROV) improved most (VIS 0.227→0.198), while ≥10 cm cases were
unchanged or marginally worse (thick snow hides the substrate; redistributing
layers to the measured depth slightly perturbs them). Having now controlled for
grain size (NIR already matched), substrate class, and snow depth, the large,
persistent **visible positive bias (~0.10–0.25) survives** — so it is cleanly
attributable to the one ingredient still absent: **light-absorbing impurities**.

At these MOSAiC melt-season sites the snow was optically dirty enough that
clean-snow radiative transfer over-predicts visible albedo regardless of what
lies beneath. The residual is therefore a *derived* quantity — the in-snow
impurity forcing — not a model failure. Turning it into a number (an effective
BC/sediment loading per site) requires either a **measured** MOSAiC
snow-chemistry / BC dataset co-located to these pits (a Path-B fetch, verified
the way the microCT was) or an explicit inversion of the visible residual —
which would be a *retrieval*, not this parameter-free closure. Adding impurities
with a fitted concentration here would lower RMSE but prove nothing.

**Bottom line of the closure:** measured snow microphysics reproduce the
grain-size-controlled NIR without tuning; the visible gap is real, robust to
substrate/thickness, and isolates impurity forcing as the dominant unmodelled
term — a clean, honest validation outcome.

## Third run — illumination sensitivity (2026-07-20)

Discriminating test for the "is it just model configuration?" hypothesis: each
pair re-run under fully **direct** vs fully **diffuse** illumination (all else at
the good config). Figure: `figures/closure_illumination_sensitivity.png`.

| illumination | median VIS RMSE | median all RMSE |
|---|---|---|
| direct beam | 0.181 | 0.123 |
| fully diffuse | 0.171 | 0.110 |

**Geometry accounts for only ~0.01–0.02 of the visible gap.** Diffuse is
slightly darker (correct direction, and physically right for the overcast
"SDNV" = solar-disk-not-visible pairs) but the ~0.10–0.25 visible bias survives
both bounds — even the cleanest site (0619 LDL) keeps a ~0.12 gap under diffuse.
So illumination configuration is **ruled out** as the dominant cause; more of
the gap than first estimated is genuine absorption the clean-snow setup omits.

Corroborating detail: several observed spectra (0715 SYI, 0721 LDL) peak in the
green and **turn down toward the blue** — the classic spectral signature of a
blue-weighted light absorber (BC/dust/algae), not of a geometry or grain-size
effect. This is positive evidence that the residual is impurity/organic
absorption, concentrated where the surfaces were dirtiest.

## Fourth analysis — banded residuals CORRECT the diagnosis (2026-07-20)

The earlier "NIR closure holds → residual is impurities" reading was **wrong**,
and the >750 nm RMSE metric that supported it was flawed: it averaged across the
1400–2000 nm ice-absorption floor where both spectra sit at ~0, which trivially
looks like agreement. Splitting the residual into physical bands
(`figures/closure_residual_spectra.png`):

| band | mean model−obs |
|---|---|
| VIS 350–700 | +0.169 |
| NIR 700–1000 | **+0.140** |
| NIR 1000–1400 | +0.067 |
| floor 1400–2000 | −0.012 (trivial) |

The over-brightness is **broadband**, nearly as large at 700–1000 nm as in the
visible, decaying to zero only at ~1400 nm. Light-absorbing impurities are
transparent beyond ~700–900 nm, so this shape **falsifies the impurity-only
hypothesis**. The control spanning 350–1400 nm is *scattering* → **grain size /
snow microstructure**: the model snow scatters too much (effective grains too
bright) for these surfaces.

**Revised diagnosis (physics vs config vs data).** *Corrected 2026-07-20 after a
literature check — an earlier draft wrongly named the SSA→radius conversion as
prime suspect; the literature rules that out (see below).*

- **Grain-radius / SSA input — BACK ON THE TABLE (earlier dismissal was a
  logic error).** A prior draft argued `r_eff = 3/(ρ_ice·SSA)` *is* the optical
  radius by construction (Grenfell & Warren 1999), so no geometric→optical
  coefficient is needed. **That conflated two separate things.** Grenfell-Warren
  yields the optical radius *only if the input SSA is the optical SSA*. microCT
  SSA is a **geometric/microstructural** measurement (total ice–air interface at
  scanner resolution); the geometric→optical conversion is a distinct step,
  upstream of Grenfell-Warren, that we never applied. G-W's equal-V/A result
  holds for convex *independent* scatterers; for bonded/clustered melt snow,
  microCT over-counts the optically-effective surface → `r_eff` too small →
  model too bright. Direction matches the residual. (The microCT-vs-optical-SSA
  study cited earlier covers SSA 5–80 m²/kg — our ~2 m²/kg melt snow is off its
  bottom, so it does not constrain this regime; that dismissal is withdrawn.)
  Published work captures this via directly-measured optical SSA and the shape/
  absorption-enhancement B and asymmetry g parameters (Libois 2013/2014; Picard
  2009), not a single universal radius coefficient.
- **Grain shape — cuts the wrong way.** Non-spherical grains scatter *less*
  forward → *higher* albedo than equal-SSA spheres (He et al. 2017/2018), so a
  shape correction would worsen the over-brightness. Not the fix.
- **Missing wetness — the leading physical cause.** Both grain levers are
  exhausted, so the broadband darkness must come from physics the clean-DRY-snow
  setup lacks. Liquid water absorbs at ~970/1190 nm, squarely in the diverging
  700–1400 nm band, and darkens broadband. Runs so far are dry (`water=0`).
- **Melting-surface / SSL optical state.** Observed peaks (0.65–0.80 visible,
  0.3–0.5 at 900 nm) are low for snow — closer to a saturated surface-scattering
  layer than a dry snowpack. microCT captures structure, not the wet optical
  state at the albedo-measurement moment.
- **Impurities — secondary, visible-only** (residual only modestly larger in VIS
  than NIR).
- **Physics/solver — not implicated** (0619 LDL nearly closes; the machinery is
  behaving). **Data — no error**, but genuinely wet/melting surfaces.

## Fifth run — wet-snow test (2026-07-20): NEGATIVE

Set liquid-water coating on the snow layers (type-0 coated spheres, 0% vs 15%
particle water fraction; `figures/closure_wetsnow_sweep.png`).

| band | dry | 15% LWC |
|---|---|---|
| VIS 350–700 | +0.169 | +0.169 |
| NIR 700–1000 | +0.140 | +0.130 |
| NIR 1000–1400 | +0.067 | +0.057 |

Liquid water removes only ~0.01 (localized at the 970/1190 nm bands) — it does
**not** close the ~0.13 NIR gap. Wet-snow is ruled out as the main term.

## Where the elimination leaves us — grain clustering / surface state

Every standard lever is now exhausted: grain-radius conversion (correct),
grain shape (wrong direction), illumination (~0.02), substrate + thickness
(small), liquid water (~0.01), impurities-alone (can't explain NIR). A uniform
~0.13–0.17 over-brightness across 350–1400 nm remains. Two candidates survive,
and a **pattern in the data discriminates toward the first:**

- **Geometric→optical SSA/radius mismatch (leading).** microCT gives a
  *geometric* SSA; Grenfell–Warren converts SSA→radius but assumes convex
  *independent* scatterers. Melt-metamorphosed snow bonds into clusters whose
  optically-effective surface is *less* than microCT's total interface area, so
  the true optical radius *exceeds* our `3/(ρ·SSA)` value → real snow darker
  than modelled. The geometric→optical step is separate from (and upstream of)
  the G-W formula and was never applied — the formula can be correct while the
  input SSA is the wrong (geometric) one.
  **Supporting pattern:** the best-fitting pair (0619 LDL) has the coarsest
  (clamped-to-1500 µm) grains and nearly closes the NIR (+0.07, even −0.04 at
  1000–1400); the worst (0721 LDL) has the finest grains (max 1483 µm) and the
  largest NIR bias (+0.25). Smaller model grains → brighter → worse, exactly as
  a clustering deficit predicts.
- **Surface-state representativeness.** Observed peaks (0.65–0.80) look like
  melting SSL / thin snow, not a clean snowpack; the microCT core samples snow
  *structure*, not the optical surface state at the albedo moment.

## Sixth run — optical-radius (geometric→optical) sweep (2026-07-20): RESOLVED

Scaled the SSA-derived radii by B∈{1,1.5,2,3} on the Pic16 LUT (native to
5000 µm; `figures/closure_grainscale_sweep.png`). Mean model−obs bias:

| r_eff ×B | VIS 350–700 | NIR 700–1400 |
|---|---|---|
| 1.0 | +0.166 | +0.095 |
| 1.5 | +0.153 | +0.041 |
| **2.0** | +0.144 | **+0.006** |
| 3.0 | +0.135 | −0.035 |

**The NIR gap closes at B≈2 while the visible barely moves** (+0.166→+0.135
across a 3× radius change). This is the decisive result: it separates the two
mechanisms that were previously conflated.

## Resolution — a clean two-term decomposition

The ~0.15 broadband over-brightness is **two independent effects in two bands**:

1. **NIR (700–1400 nm) → optical grain radius too small.** microCT's *geometric*
   SSA, via Grenfell–Warren's independent-sphere formula, under-sizes the optical
   grain of clustered melt snow; a **B≈2 optical-radius correction closes it.**
   This is the geometric→optical mismatch — a model-*applicability* finding, and
   physically credible (optical grain ≈ 2× the independent-sphere SSA radius for
   bonded melt snow). Not a solver bug: the fix is an input correction.
2. **Visible (350–700 nm) → light-absorbing impurities.** The visible residual
   (~+0.14) is nearly **grain-size-independent** (moves <0.03 across the sweep),
   because ice is transparent there. After the grain fix it stands alone as the
   VIS-only term — exactly the impurity signature, now correctly isolated to the
   band where impurities act.

So both earlier ideas were right but mis-assigned: the residual is **grain-size
(optical radius) in the NIR + impurities in the visible**, and the B-sweep
cleanly resolves which is which. Per-pair, the required B correlates inversely
with the raw SSA grain size (0619 LDL, coarsest raw grains, needs B≈1 and
overshoots beyond; 0704/0721, finest, need B≈3) — consistent with clustering
that depends on local melt-metamorphism state, i.e. B is not a universal constant.

**Bottom line for BioSNICAR:** not a physics/solver error and not a data error —
a model-*applicability* limit. Driven by independent-sphere geometric-SSA radii,
it over-predicts melt-snow albedo in the NIR; an optical-radius (cluster)
correction of ~2× resolves it, leaving a clean visible impurity residual.
Next, if pursued: derive B physically (metamorphism/cluster models or measured
optical SSA) rather than by fit, and quantify the VIS impurity term against a
measured MOSAiC snow-chemistry dataset (Path-B).
